# 手势切西瓜 · Gesture Fruit

用**食指指尖**切掉下落西瓜的浏览器小游戏。纯原生 HTML + CSS + JS，无构建、无框架，摄像头 + 浏览器即可运行。

> 维护者：[@Evelyn11290000](https://github.com/Evelyn11290000)

## 玩法

- 画面随机生成**西瓜**与**炸弹**，一起匀速下落（170 px/s）
- 食指指尖碰到西瓜 → 西瓜消失，分数 +1
- 食指指尖碰到炸弹 → 炸弹消失，扣 1 滴血；**3 滴血掉光游戏结束**
- 移动时留下**刀痕**（指尖轨迹），坐标经过 8 帧滑动平均滤波
- **握拳**切换暂停 / 继续

## 运行

因为 `getUserMedia` 只在安全上下文可用，**不能直接双击打开 `index.html`**（`file://` 协议会被浏览器拒绝），需要起一个本地 HTTP 服务：

```bash
# 在仓库根目录执行
python3 -m http.server 8130
```

然后浏览器打开：

```
http://127.0.0.1:8130/gesture-fruit/index.html
```

首次打开需允许摄像头权限。

## 目录

| 文件 | 说明 |
|---|---|
| `index.html` | 全部代码：样式、游戏逻辑、手势状态机、绘制 |

单文件是有意为之，与仓库里 `gesture-test/` 的组织方式一致。

## 技术要点

| 模块 | 说明 |
|---|---|
| 手部检测 | MediaPipe Hands（WASM），只跟踪 1 只手，取 landmark `8` 作为食指指尖 |
| 坐标映射 | 画面左右镜像显示，指尖屏幕坐标 = `(1 - x) * 宽` |
| 滤波 | 8 帧滑动平均，窗口长度由 `SMOOTH_WINDOW` 控制，代价是约 130ms 滞后 |
| 刀痕 | 保留最近 16 个平滑点，新点更粗更亮；相邻点间距小于 4px 不记录 |
| 碰撞 | 圆-圆相交：`圆心距 ≤ 西瓜半径 + 指尖半径(22px)` |
| 防重复计分 | `consumed` 标记 + 同目标 400ms 冷却窗口（`hitLog`） |
| 状态机 | `playing` / `paused` / `over`，只有 `playing` 会推进游戏 |
| 握拳判定 | 21 关键点相对距离；四指弯曲 + 指尖贴近掌心 + 拇指内收，且手不在快速挥动中 |
| 手势确认 | 候选连续 4 帧 + 保持 220ms 才生效，带 900ms 动作冷却 |

## URL 参数（现场试参）

```
?gEnter=4&gHold=220&gMotion=0.5&gPalm=0.55&gCooldown=900&gFinger=1.2&gThumb=1.25&hitCd=400
```

| 参数 | 默认 | 作用 |
|---|---|---|
| `gEnter` | 4 | 候选手势连续帧数才确认切换 |
| `gHold` | 220 | 候选最少保持时长（ms） |
| `gMotion` | 0.5 | 挥手判定：掌心每帧位移 / 掌长，超过则忽略手势 |
| `gPalm` | 0.55 | 握拳时「指尖到掌心 / 掌长」的上限 |
| `gCooldown` | 900 | 动作冷却（ms） |
| `gFinger` | 1.2 | 手指伸直判定倍数 |
| `gThumb` | 1.25 | 拇指伸直判定倍数 |
| `hitCd` | 400 | 同一目标最短重复结算间隔（ms） |

**误触发调参**：切西瓜时容易误暂停，就加大 `gMotion`（如 0.7）或 `gHold`（如 300）；握拳要举很久才暂停，就减小 `gEnter`（如 3）。

## 已知限制

- **依赖 CDN**：`@mediapipe/hands` 与 `@mediapipe/camera_utils` 从 jsdelivr 加载（版本已固定为 `0.4.1675469240` / `0.3.1675466862`）。**断网环境无法运行**；仓库内 `gesture-test/` 走的是本地 `vendor/` 方案，如需离线演示应改用那一套。
- 滑动平均会带来约 130ms 的轨迹滞后，快速挥动时刀痕末端略拖。可通过减小 `SMOOTH_WINDOW` 换取更跟手。
- 握拳判定为几何启发式，强逆光或手离镜头过远时可能失效。

### 量化限制

| 限制 | 依据 | 影响 |
|---|---|---|
| 均匀权重滑动平均 | `SMOOTH_WINDOW=8`，取算术平均 | 约 130ms 滞后；快速挥动时判定点落后真实指尖，刀痕末端拖尾 |
| 只跟踪 1 只手 | MediaPipe Hands 单目标 | 第二只手的指尖不参与判定 |
| 握拳暂停是纯几何启发式 | 四指弯曲 + 指尖贴掌心 + 拇指内收 + 不在快速挥动中 | 不同手型（大小手、手指长短）下阈值未必通用 |
| 离线不可用 | `@mediapipe/*` 从 jsdelivr 加载 | 断网环境直接白屏，没有本地兜底 |

**未验证（需要真机数据）**：

- 握拳暂停的真实误触发率没有实测数字（上文只给了「误暂停就调大 `gMotion` / `gHold`」的经验建议）；
- `gFinger=1.2` / `gThumb=1.25` 在不同手型下的通用性没做过跨人验证；
- 低帧率设备（<30fps）下 8 帧窗口的实际滞后会明显大于 130ms，未量化。
