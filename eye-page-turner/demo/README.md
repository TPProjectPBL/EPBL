# 双模态交互 Demo · 隔空画画 / 星际跑酷

用**眼动 + 手势**实现免接触人机交互的两个演示页面。纯前端，无构建工具、无框架。

> 维护者：[@Evelyn11290000](https://github.com/Evelyn11290000)

| 目录 | 页面 | 一句话说明 |
|---|---|---|
| `air-draw/` | 隔空画画 | 握拳落笔、张开抬笔，用视线或指尖当笔尖 |
| `air-runner/` | 星际跑酷 | 眼动变道 + 手势跳/滑/护盾 |

## 运行

必须通过 HTTP 访问（`getUserMedia` 只在安全上下文可用，`file://` 会被拒绝）：

```bash
# 在仓库根目录执行
python3 -m http.server 8130
```

- 隔空画画：`http://127.0.0.1:8130/eye-page-turner/demo/air-draw/index.html`
- 星际跑酷：`http://127.0.0.1:8130/eye-page-turner/demo/air-runner/index.html`

两个页面都依赖上一级的 `../src/`（摄像头、检测器、状态码），必须整个 `eye-page-turner/` 目录一起部署。

## 隔空画画 `air-draw/`

### 交互映射

| 操作 | 输入 |
|---|---|
| 落笔 | 握拳 |
| 抬笔 | 张开手掌 |
| 选色 | 注视调色板 + 停留 700ms（带进度环） |
| 笔尖位置 | 视线（默认），或食指指尖（更稳，适合实际绘制） |

笔刷可调**粗细**、**浓淡**，另有发光笔 / 纸质底两种画布风格，以及撤销、清空。

### 设计要点

- 手势用**手部状态二分类 + 滞回防抖**，避免落笔/抬笔在临界点抖动
- 笔迹经 One Euro 滤波平滑
- **兜底**：摄像头不可用时自动进入「演示模式」，页面不会开天窗

## 星际跑酷 `air-runner/`

### 输入模式

用 URL 参数 `?mode=` 切换：

| 模式 | 说明 |
|---|---|
| `dual` | 眼动变道 + 手势跳/滑/护盾（推荐） |
| `gaze` | 只眼动（跳/滑用键盘兜底） |
| `hand` | 只手势（左右挥手变道） |
| `mouse` | 鼠标 + 键盘，无摄像头也能走完整流程 |
| `sim` | 自动演示，无需摄像头，用合成关键点走真实检测链路 |

### 眼动标定

进入页面后按提示做 **9 点标定**（也可用 `?gazecal=1` 直接进入）。标定数据存在浏览器 localStorage，换会话后建议重新标定。

### 模块划分

`app.js` 只做编排，算法都在 `lib/`：

| 文件 | 职责 |
|---|---|
| `router.js` | 屏幕路由 |
| `dwell.js` | 视线停留点击（菜单、暂停按钮） |
| `gaze-zone.js` | 三区注视 → 变道 |
| `gesture.js` | 挥手 → 跳/滑，握拳 → 护盾 |
| `kalman.js` | 视线卡尔曼平滑 |
| `gaze-calib.js` | 9 点标定 + 岭回归注视点预测 |
| `gaze-online.js` | 点击样本在线增量校正 |
| `runner.js` | 跑酷本体（占位实现） |

## 已知限制

- 一次性标定的视线精度不足以跨会话复用，**每次演示前需重新标定并保持坐姿**
- 手势在 1–2 米距离、强逆光或手部出画时会误判
- 跑酷本体（`runner.js`）当前为占位实现，玩法深度有限
- 两个页面依赖外部 CDN 上的 MediaPipe 脚本；离线环境需改用仓库内 `vendor/` 方案
