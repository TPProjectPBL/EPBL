## 二、本地运行

摄像头受 `getUserMedia` 限制，**必须**在 `localhost` 或 HTTPS 下打开：

```bash
cd EPBL && python3 -m http.server 8777 --bind 127.0.0.1
# 正常体验（默认视线控制笔尖）
open http://127.0.0.1:8777/eye-page-turner/demo/air-draw/
```

| 参数 | 作用 |
| --- | --- |
| （无） | 显示 10 秒引导 → 点「开始体验」申请摄像头，默认**视线**控制笔尖 |
| `?input=hand` | 改为**食指指尖**控制笔尖（更稳、更好画，作为现场备选） |
| `?input=mouse` | 鼠标兜底：按住拖动 + 点色板选色 |
| `?input=sim` | 演示模式：模拟数据自动作画（**无需摄像头**，可直接在产物面板/浏览器打开预览） |
| `?autostart=1` | 跳过引导层（展台 kiosk 用） |

兜底链路是自动的：`boot()` 里摄像头异常（权限拒绝 / 无设备 / 非安全上下文 / 检测器加载失败）会捕获 `PluginError.code`，翻译成中文提示后**自动切到鼠标模式**，页面永远不会开天窗。

## 三、交互映射（对照 §9 规格）

| 规格要求 | 实现 |
| --- | --- |
| 落笔 = 握拳，抬笔 = 张开手掌，**需滞回防抖** | `classifyHand()` 用四指伸直数 + 拇指尖↔小指尖/掌宽判定；中间地带（1<伸直≤2）一律 `unknown` 即滞回带；状态机要求连续 3 帧一致 + 160ms 冷却才切换 |
| 手离开画面不乱画 | 超过 400ms 未见手 → **强制抬笔**（`lostTimeoutMs`） |
| 选色 = 注视颜色面板 + dwell + 进度环 + 误触抑制 | `PaletteDwell`：dwell 700ms（报告建议 600–900ms），`--dwell` 驱动 conic-gradient 进度环；三层抑制＝①速度 >0.6 不累积（扫视不误触）②选中后须移出该色块再进入（长盯不连选）③350ms 冷却 |
| 单次体验 30–60s、零学习成本、10 秒内理解 | 引导层三步图文 + 10 秒后自动隐藏并进入演示模式；HUD 常驻提示当前该做什么 |
| 决策 8「分时复用：选色时手放低，绘制时专注手势」 | 光标进入调色板 → `overPalette` 为真 → **暂停落笔**（不会把选色轨迹画到画布上），离开即恢复 |
| 风险「手遮挡面部导致眼动丢失」 | 手部包围盒 ∩ 人脸包围盒覆盖率 > 0.26 → `occluded` → 画笔**冻结** + 吐司提示「请把手移开」+ 笔尖指示器变黄 |
| 导出 PNG | `BrushEngine.exportPNG()` 按 CSS 单位 + DPR 重绘导出，底纹烘焙进图片；「完成 · 生成作品」弹出作品卡片，可下载 / 再画一幅 |
| UI 不直接引用 MediaPipe | UI 层只消费归一化坐标与事件；模型对象仅存在于 `app.js` 的采集层 |

坐标系约定（容易踩坑，已固化）：预览以 `scaleX(-1)` 镜像 → 光标 `x = 1 - image_x`、`y = image_y`；`gain≈1.9~2.0` 以 0.5 为中心扩张并 clamp 到 `[0.02,0.98]`，保证小幅度动作也能画满画布。

## 四、可插拔点（给阶段 3 预留）

**关键前提：报告阶段 3「眼神方向估计」尚未交付，因此当前没有真实视线落点。**
`lib/gaze-source.js` 里的 `GazeCursorSource` 是**代理实现**：用虹膜在眼眶包围盒内的相对偏移做粗略映射（左虹膜 468 / 右虹膜 473，眼眶角点 33/133、362/263，上下眼睑 159/145、386/374，用 min/max 归一避免左右眼方向假设）。

- 接口固定为 `getPoint(results) → {x, y, conf} | null`，**阶段 3 交付后只需替换该方法内部实现，`app.js` 与 UI 不动**。
- 精度**不足以**直接当产品级视线估计使用：现阶段现场演示建议用 `?input=hand`（指尖）作为主控，眼动负责「选色」这一离散动作 —— 这也正是报告里眼动最擅长、误差最不敏感的部分。

## 七、彩排清单（建议现场前跑 3 遍）

1. **彩排 1 · 正常路径**：默认 `?input=gaze`，确认摄像头权限、距离 0.6–1.0m、光线充足；志愿同学完成一幅画并导出。
2. **彩排 2 · 降级路径**：改用 `?input=hand`（指尖控笔），对比两版观感与稳定性，**拍板现场用哪版**；顺手测「手挡住脸」的冻结提示。
3. **彩排 3 · 断网/无设备**：拔掉摄像头 / 拒绝权限 → 确认自动进入演示模式不黑屏；另备一条 `?input=sim` 直达链接；离线场景需提前把 MediaPipe CDN 三个脚本本地化（当前依赖 jsdelivr）。

现场速记：**握拳落笔、张开抬笔、看色块 0.7 秒换色**；画笔不对就用鼠标兜底，画布从来没有导出失败的风险（导出走 canvas，纯本地）。
