# 统一标定（v2）实现说明

> 目标：把原来「各页各标一次 / 9 点 + 手势点亮 / 仅测试」的标定，替换为一条统一、强制、可验证的流程。
> 实现时间：2026-11-21。代码入口：`shared/gaze/calibrate/`、`shared/gaze/idb.js`、`workbench/gaze-host.js`。

## 1. 流程（唯一路径）

```
进入工作台（未完成本次会话标定）
  → #/calibrate 强制 9 点标定
     先出居中摄像头弹窗：把脸放进虚线框，头稳住后自动 3-2-1
     每点固定采样 1000ms；无脸 / 眨眼 / 头位不合格只丢帧，进度不回落、不重来
     点与点之间停 1 秒（9 个靶点全程可见；下一个点外圈闪两下作为起拍提示）
  → 等权岭回归（alpha=1.0，二阶多项式，14 项）
  → 3-2-1 倒计时 → 5 点测试（四角 + 中心），每点固定 1 秒
     测试阶段不稳定只丢帧、不重来；1 秒一到就按已采帧评分
  → 正确率 >= 60 分（等价平均误差 <= 0.16）：写入 IndexedDB → 进入主应用
  → < 60 分：只给「重新标定 / 跳过」两个出口
```

- 没有「等眼球到位」的 settle 阶段，也没有鼠标点亮靶点的步骤：点出现即开始计时。
- 不会用动画假装采样：每个点必须累计 1000ms 的**有效帧**才结算；模拟模式（`?gazeSim=1`）直接拒绝标定。
- 进度环不是墙钟：同一帧被重复调用、摄像头停流（>400ms 没有新帧）、标签页被节流，都不累计时间。
- 标定前先出**居中摄像头弹窗**（320×240）：虚线「标准框」+ 实时头框，顶部写「对准摄像头 · 把脸放进虚线框」；
  头位连续稳定后才 3-2-1，倒计时显示在弹窗下方，靶点全程可见。
- 倒计时结束弹窗收成右下角小窗（236×177），标定与测试全程保留，标准框不随头移动；
  小窗不再淡出，靶点层级在小窗之上（右下角那个点也点得到）。
- 头框/徽标只有两态：合格绿、不合格红（不留黄/灰中间态）。
  不合格直接写「太远 · 请靠近一点」「太近 · 请稍微离远一点」「请回到画面中央」
  「头歪了 · 请回正」「头位偏了 · 请对准虚线框」。
- 头位门槛完全沿用 gaze-heatmap 融合前版本（`shared/gaze/contract.js` 的 `HEAD` 与
  `headDelta()`），不再用单一 10° 硬阈值。
- 跳过验证仍会写入模型，但状态标记为 `stale`（建议重标）。

## 2. 参数（`shared/gaze/calibrate/protocol.js`）

| 项 | 值 |
| --- | --- |
| 标定点 | 3×3：x = 0.1 / 0.5 / 0.9，y = 0.12 / 0.5 / 0.88 |
| 验证点 | (0.06,0.06) (0.94,0.06) (0.5,0.5) (0.06,0.94) (0.94,0.94) |
| 单点采样 | 1000 ms |
| 眨眼阈值 | EAR < 0.2 |
| 头位门控 | 脸高 0.22~0.80、居中 0.17/0.20、roll 12°、yaw 17°、pitch 5~68°（绝对） |
| 相对基准 | 位移 0.055 / 0.065 / 0.10，角度 5° / 7° / 8°（roll / yaw / pitch） |
| 点间隔 | 1000ms（9 个靶点可见；标定与测试都停；下一个点外圈闪 2 下） |
| 开始倒计时 | 弹窗内头稳 12 帧 → 3-2-1；测试前也 3-2-1 |
| 测试评分 | 单点正确率 = clamp(1 - 误差/0.4)×100，60 分 = 0.16 误差 |
| 帧新鲜度 | 超过 400ms 没有新帧 → 暂停推进，进度不清零（`stale`） |
| 单帧计时上限 | 120ms（掉帧/卡顿不补时间） |
| 视线游走 | 窗口内 dLx/dLy 标准差 > 0.12 → 丢该帧（`jitter`） |
| 没看靶点 | 与上一点的眼球特征位移 < 0.012 → 跳过该点，不重来（`noGaze`） |
| 离群帧 | 单帧偏离窗口均值 > 0.28 → 丢弃该帧，进度不归零 |
| 单点兜底 | 头一直不稳时 8 秒后按已有帧结算（不少于 3 帧才入样） |
| 回归 | 等权岭回归，alpha = 1.0，二阶多项式 |
| 验证阈值 | 平均欧氏距离 <= 0.08（PAGE_NORM） |
| 存储 | IndexedDB `epbl-gaze` / `models` / 固定键 `gaze_model` |

## 3. 镜像

所有关键点在使用前统一执行 `x = 1 - x`（`shared/gaze/core/mirror.js`）。
训练、头姿、预测必须走同一份镜像坐标；`headPose()` 的 roll 已改为 `atan2(dy, |dx|)`，避免镜像后跳到 ±180°。

## 4. 唯一模型源

- 写入：只由工作台 `finishUnified()` 写入 IndexedDB，每次覆盖。
- 读取：`shared/gaze/idb.js` 的 `readPredictor()` / `page-bridge.primeSharedModel()`。
- 子项目启动读不到模型：`requestHostCalib()`（iframe）或跳转 `/workbench/index.html#/calibrate`。
- 在线学习（点击即训练）默认关闭：模型系数只能来自统一标定，模块不得在运行时改写。

## 5. 自检

```bash
node scripts/test-unified-calib.mjs   # 协议 / 状态机 / 不重来 / 弹窗稳定 / 镜像
node scripts/test-gaze-core.mjs       # 旧特征与拟合回归
```

真机验收（必须在有摄像头的机器上）：

1. 打开 `http://127.0.0.1:8125/workbench/index.html` → 自动进入 9 点标定。
2. 先出现居中摄像头弹窗，把脸放进虚线框并保持不动；头不稳时一直等，稳住后弹窗下方出现 3-2-1。
3. 9 个点每个都能看到进度环走满 1 秒，点与点之间停 1 秒，倒计时/停顿期间 9 个点都不许消失。
4. 故意离远/凑近/歪头/转头，小窗头框立刻变红并提示原因，但**进度环不会回零**，
   恢复后从原处继续；用手挡住摄像头，进度停住但不清零。
5. 测试阶段故意眨眼，进度不会重来，但该点正确率会下降。
6. 5 点测试后显示「正确率 xx 分」；>= 60 分直接进主应用。
7. 点右上角「回到首页」会保留已完成点数，首页显示「继续标定 n/9」。
8. 打开 DevTools → Application → IndexedDB → `epbl-gaze` → `models` → `gaze_model` 应为每次标定后的新记录。
