# 眼动翻页插件 · 操作说明（阶段 3）

一款基于 Web 的双模态翻页插件：检测引擎在**后台隐式运行**，通过摄像头识别用户距离与姿态，自动在「眼神 / 手势」两模式间切换，并**跨页面控制主页面翻页**。

## 1. 架构

```
┌─────────────────────┐   BroadcastChannel   ┌──────────────────────┐
│  检测引擎 index.html │ ── 翻页/模式指令 ──▶  │  主页面 reader.html    │
│  （隐式后台运行）      │                      │  （被控，自动滚动翻页）  │
└─────────────────────┘                      └──────────────────────┘
```

- **检测引擎**（`index.html`）：运行摄像头 + MediaPipe 检测，生成翻页指令，通过 `BroadcastChannel`（同源跨标签页）广播。支持「隐式模式」折叠画面，后端运行不干扰主页面。
- **主页面**（`reader.html`）：用户真正浏览的内容页，监听指令并执行滚动翻页。

> 两者需在同一浏览器、同一 `localhost` 源下打开（BroadcastChannel 要求同源）。

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome / Edge / Safari（较新版本） |
| 摄像头 | 前置摄像头（笔记本自带即可） |
| 网络 | 需联网（MediaPipe 模型脚本走 CDN） |
| 访问方式 | 必须通过 `localhost` 起服务，浏览器才会授权摄像头 |

## 3. 启动步骤

1. 在项目目录启动静态服务（端口可自定义，下面以 8124 为例）：

   ```bash
   cd /Users/xu/Desktop/project/PBL/eye-page-turner
   python3 -m http.server 8124
   ```

2. **打开主页面**（另开一个标签页）：

   ```
   http://localhost:8124/reader.html
   ```

3. **打开检测引擎**（另一个标签页）：

   ```
   http://localhost:8124/index.html
   ```

4. 在检测引擎页点击「**启动摄像头**」并授权，待顶栏显示「广播：运行中」。

5. 回到主页面做手势/移动视线，页面自动滚动翻页。

> 建议：将检测引擎页窗口缩小或点击「隐式模式」，放到一旁，主页面保持全屏专注阅读。

## 4. 距离标定（建议一次，更准确）

1. 站在一个**已知距离**处（建议 **1 米**），正对镜头，双眼可见。
2. 确认「实时检测」中「人脸」「虹膜」均为**已检测**（绿色）。
3. 在「距离标定」面板确认参考距离为 `1.0` 米，点击「**标定**」。

> 未标定时使用默认经验参数，距离为粗略估计；标定后更准确。

## 5. 双模态与翻页指令

| 模式 | 触发条件 | 翻页动作 |
| --- | --- | --- |
| 👁 眼神模式（近距） | 距离 ≤ 1.3m | 向上看 → 上一页 · 向下看 → 下一页 |
| ✋ 手势模式（远距） | 距离 ≥ 1.7m | 手掌举高 → 上一页 · 手掌放低 → 下一页 |

- **切换阈值** 1.5m；**迟滞带** 1.3m ~ 1.7m 保持当前模式，避免临界抖动。
- **指令稳定性**：目标方向需连续 5 帧确认才触发；触发后进入 0.8s 冷却；信号回中后才可再次触发，防止一次动作连翻多页。

## 6. 隐式模式

检测引擎页顶栏的「**隐式模式**」按钮：点击后摄像头画面与侧栏折叠，仅保留一条紧凑状态栏，视频采集在后台持续运行，不干扰你对主页面的阅读与操作。再次点击「退出隐式」恢复完整界面。

## 7. 界面说明

- **检测引擎顶栏**：模式 / 摄像头 / FPS / 广播状态胶囊 + 隐式模式开关。
- **「当前模式」**：大徽章（绿=眼神、金=手势）+ 人屏距离数值与进度条（金色刻度为 1.5m 阈值）。
- **「翻页指令」**：展示当前手势/眼神对应的翻页方向，触发时提示「已发送翻页指令」。
- **主页面顶栏**：连接状态 + 当前模式；翻页时顶部弹出「▲ 上一页 / ▼ 下一页」提示。

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 主页面不翻页 | 确认检测引擎已「广播：运行中」；两页需同一 `localhost` 源 |
| 打不开摄像头 | 通过 `localhost` 访问；检查浏览器摄像头权限 |
| 提示「非安全上下文」 | 必须用 `http://localhost` 或 HTTPS，不能用 `file://` |
| 标定失败 | 未检测到双眼虹膜，正对镜头、光线充足后再试 |
| 翻页太灵敏/连翻 | 调整 `page-controller.js` 的 `cooldownMs` / `minFrames` |
| 隐式模式后无画面 | 正常现象，画面已折叠；顶栏状态仍实时更新 |

## 9. 技术参数（阶段 3）

- **距离估计**：`距离 = K / 瞳距像素`；标定 `K = 参考距离 × 参考瞳距`；EMA 平滑 0.35。
- **模式切换**：阈值 1.5m，迟滞 ±0.2m，连续 5 帧确认。
- **翻页指令**：连续 5 帧确认 + 0.8s 冷却 + 回中复位；手势取 landmark 9、视线取虹膜相对眼眶偏移。
- **通信**：`BroadcastChannel("eye-page-turner")`，消息类型 `page` / `mode` / `status` / `ping` / `pong`。
- **检测**：MediaPipe Face Mesh（468 点 + 虹膜）、Hands（21 点）。
