## P4 · 眼动链路：把模型搬进本地

**标题**
> 眼动链路：把模型搬进本地

**要点（4 条）**
- WebGazer 2.1.2 + FaceMesh 模型全部放进 `vendor/`，断网可用
- 踩坑一：模型路径是「相对页面」的，换页面就 404
- 修法：改成站点绝对路径 `/controller-demo/vendor/.../model.json`
- 踩坑二：视频不能 `display:none`，否则黑帧；启动前做权限/占用/黑帧预检

**右侧：代码对比（小窗）**
```
- FACEMESH_GRAPHMODEL_PATH = "./facemesh_model/model.json"
+ FACEMESH_GRAPHMODEL_PATH = "/controller-demo/vendor/webgazer/facemesh_model/model.json"  // [EPBL patch]
```
文件：`controller-demo/vendor/webgazer/webgazer.js:50869`

**底部小字**
> 采集统一提升到 1080p；眼动与手势共用同一路视频流，不重复开摄像头

**讲稿（约 50 秒）**
> 眼动这块最大的工作量不是调参，是「让它稳定地跑起来」。我们把 WebGazer 和 FaceMesh 的模型全部搬进仓库，好处是断网也能用，代价是仓库变大。中间踩了两个坑：一是模型路径写成了相对当前页面，只有旧控制器页面能加载，其他页面全 404，我改成站点绝对路径；二是 WebGazer 的视频元素一旦隐藏就黑帧，所以启动前必须先做预检，把「权限拒绝、被占用、黑帧」三种情况分开提示，而不是笼统报错。

## P10 · 三个关键机制

**标题**
> 三个关键机制

**三列卡片**

**① 摄像头单实例互斥**
- 切换前先把 iframe 设成 `about:blank` 再移除
- 实测：旧视频轨道 `live → ended`
- 连续 5 次快速切换，始终只有 1 个 iframe

**② hash 路由 + 深链回退**
- `#/模块名` 可直接分享
- 未知模块自动回退默认页，不白屏

**③ 下载中心联动**
- `releases.json` 驱动卡片
- 体积、版本、SHA-256 同屏展示
- 点击即下载，hash 可核对

**讲稿（约 50 秒）**
> 工作台有三个容易被忽略、但决定好不好用的机制。第一是摄像头互斥：切模块时如果直接删 iframe，摄像头可能还被旧页面占着，新页面就黑屏。我们的做法是先把它导航到空白页，让浏览器释放轨道，再移除。第二是路由：每个模块有独立地址，未知地址回退默认页，不会白屏。第三是下载中心，安装包的信息和校验值直接从 JSON 读，改包不用改页面。

**制作提示**
- 三个卡片标题前用 ①②③，不要用 emoji。

## P11 · 打包分发：让别人也能打开

**标题**
> 打包分发：让别人也能打开

**流程（横向 4 步）**
```
源码
 → py2app 打成 .app
 → 首次启动自举（venv → pip → Chromium）
 → DMG 拖拽安装
```

**关键修复（1 条）**
> py2app 会注入 `PYTHONHOME`，导致创建 venv 直接失败；启动器现在会清空全部 `PYTHON*` 变量再自举。

**产物（1 行）**
> DMG 含 `.app` + `Applications` 快捷方式 + 安装说明

**讲稿（约 50 秒）**
> 最后一个问题是交付。同学拿到源码，装 Python、装依赖、装浏览器，基本会卡住。所以我用 py2app 把它打成 macOS 应用，首次启动自动创建运行环境、安装依赖、下载 Chromium，之后就直接打开工作台。这里有个很隐蔽的坑：py2app 会往环境里注入 PYTHONHOME，导致我们自己的 venv 创建失败。修法是启动前把所有 PYTHON 开头的变量清掉。最后封成 DMG，拖进应用程序就能用。

**制作提示**
- 四步流程用箭头串联，第二步下面标注「约 2 分钟，需联网」。

## Q&A 预案（不放进 PPT，给汇报人）

**Q1：为什么用 iframe，不直接重写成单页应用？**
> 因为模块是不同人、不同技术栈写的，重写等于接管别人的代码，风险和成本都高。iframe 能做到样式隔离、摄像头隔离，原页面还能独立打开，迁移成本最低。

**Q2：眼动精度到底多少？**
> 口径已经定死：平均偏差 70 像素、命中率 80%、单次 3 秒。真机复测还没补齐，所以今天不报具体数字。测试台和导出都在，复测只需要人坐下来跑一轮。

**Q3：为什么不直接发源码，非要打包？**
> 源码需要 Python、依赖、浏览器三样东西，非技术同学基本装不起来。打包后是拖拽安装，首次启动自动准备环境，这是能不能交到别人手里的区别。

**Q4：68 MB 是不是太大了？**
> 大在模型和推理运行时，换来的是断网可用、不依赖 CDN。如果要压，可以砍掉暂时不用的 vendor，但会牺牲离线能力。

**Q5：热力图是你做的吗？**
> 算法是 yuanheyiiii 的，我负责把它接进工作台、统一入口和分发。这也是为什么我在第二页先把边界讲清楚。
