二、产品态（实际阅读场景） UI 必须「隐身」，只在该说话时说话

翻页插件的前提是「用户正在读东西」。任何常驻遮挡都是负体验。默认只留一个吸附在边缘的呼吸点，动作发生时短暂现身 800ms 后自动淡出；摄像头预览绝不常驻。

第三章 · 双模态切换的迟滞设计

设计报告 v2.0 · 第 7 节

为避免用户在 1.5m 临界距离反复横跳时触发模式抖动，切换逻辑引入迟滞带：进入近距离需低于 1.3m，退回远距离需高于 1.7m，并附加切换后的动作冷却。

这一设计使得「切过去就不再切回来」，代价是切换存在约 0.4m 的缓冲区——这也是 UI 必须在视觉上把迟滞带表达出来的原因。
